# Науково-учнівський журнал «Екологічний вісник» №7/2026

Інтерактивний вебсайт-вітрина конкурсного дослідницького проєкту на тему **«Роль АЕС під час воєнного стану в Україні»** (Всеукраїнський конкурс рефератів серед учнівської молоді **«Ядерна енергетика і світ»**).

- **Автор:** Антонюк Єгор Іванович (студент гр. 67-р/к ЗП(ПТ)О «Південноукраїнський професійний коледж»)
- **Науковий керівник:** Мітченко Олена Анатоліївна (викладач біології, «Викладач-методист»)
- **Епіграф випуску:** *«Не думки слід навчати, а думати!» — І. Кант*

## Структура проєкту

- `index.html` — основна сторінка журналу та інтерактивних розділів
- `assets/css/style.css` — стилізація, світла/темна теми, стилі друку й презентаційного режиму
- `assets/js/main.js` — інтерактивна карта ПАЕС, SVG-графік АСКРО, монітор населених пунктів, симулятор 3-рівневого захисту, вікторина та 14-слайдовий режим показу
- `assets/images/` — ілюстрації, схеми, карти та фотоматеріали дослідження

## Локальний перегляд

Відкрийте `index.html` у будь-якому сучасному браузері або запустіть локальний HTTP-сервер:

```bash
python -m http.server 8000
```

## Публікація на GitHub Pages

1. Завантажте всі файли репозиторію у гілку `main`.
2. У налаштуваннях репозиторію відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** виберіть **Deploy from a branch**, гілка `main`, папка `/ (root)` і натисніть **Save**.
