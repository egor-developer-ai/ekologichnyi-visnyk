# Науково-учнівський журнал «Екологічний вісник»

Багатостатейний вебпортал та презентаційна платформа студентського наукового журналу ЗП(ПТ)О «Південноукраїнський професійний коледж» (конкурс **«Ядерна енергетика і світ»**).

- **Живий сайт:** https://egor-developer-ai.github.io/ekologichnyi-visnyk/
- **Головний випуск №7/2026:** «Роль АЕС під час воєнного стану в Україні» — Антонюк Єгор Іванович (науковий керівник: Мітченко Олена Анатоліївна)
- **Додаткові демо-макети (№8–№11/2026):** готові шаблони статей, інтерактивних блоків та 5-слайдових презентацій для майбутнього наповнення роботами одногрупників та викладачів
- **Стрічка новин:** актуальні редакційні новини, моніторинг АСКРО та оголошення про підготовку матеріалів

## Структура проєкту

- `index.html` — головний каркас порталу, випуск №7/2026, каталог статей, стрічка новин, редакційний довідник і модальні вікна
- `assets/css/style.css` — стилізація, світла/темна теми, стилі перемикача статей, каталогу, новин, друку й презентаційного режиму
- `assets/js/articles-data.js` — база статей журналу (`ECO_JOURNAL_ARTICLES`) та новин (`ECO_JOURNAL_NEWS`) для швидкого розширення
- `assets/js/main.js` — перемикання статей, фільтрація/пошук, інтерактивні модулі (карта ПАЕС, АСКРО, 3-рівневий захист, вікторина) та адаптивний режим презентації
- `assets/images/` — ілюстрації, схеми, карти та фотоматеріали дослідження

## Як додати нову статтю або замінити демо-шаблон

1. Покладіть нові фото/графіки у теку `assets/images/`.
2. Відкрийте `assets/js/articles-data.js` та додайте новий об’єкт у `ECO_JOURNAL_ARTICLES` (або замініть текст у `№8`–`№11/2026`, змінивши `status` на `'verified'`).
3. Щоб додати новину — додайте об’єкт у `ECO_JOURNAL_NEWS`.

## Локальний перегляд

Відкрийте `index.html` у будь-кому сучасному браузері або запустіть локальний HTTP-сервер:

```bash
python -m http.server 8000
```

## Публікація на GitHub Pages

1. Завантажте всі файли репозиторію у гілку `main`.
2. У налаштуваннях репозиторію відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** виберіть **Deploy from a branch**, гілка `main`, папка `/ (root)` і натисніть **Save**.
